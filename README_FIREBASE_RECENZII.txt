SUC DE LA PROFU' — RECENZII FIREBASE

1. Încarcă toate fișierele în repository-ul GitHub.
2. Așteaptă publicarea GitHub Pages.
3. Acceptă notificarea de actualizare PWA sau închide și redeschide aplicația.
4. Deschide recenzii.html și publică o recenzie de test.
5. În Firebase > Firestore > Data va apărea automat colecția reviews.

Recenziile sunt publicate automat. Numele, localitatea, nota, textul și data sunt salvate în Firestore.
